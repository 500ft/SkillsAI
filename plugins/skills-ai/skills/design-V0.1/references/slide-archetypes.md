# Stoic Lesson Slide Archetypes

A catalog of slide layouts for narrate-over lessons, derived from a teardown of the Stoic Edu
Lesson 0.3 deck (19 slides) and corrected against the design system. Pick an archetype per slide;
fill with real content; keep on-screen prose ≤ ~20 words (data/labels exempt).

Grounds alternate by type to avoid the "same background 19×" tell. `navy` = `--navy` ground +
`--cream` text; `parchment` = `--parchment` ground + `--ink` text.

---

### 1. Title / Cover  — `navy` + seal
Kicker lockup (`STOIC EDUCATION · MODULE 00 · LESSON 0.3`), oversized Fraunces title (the promise),
one-line subhead, seal top-right or centered. Footer + `01 / NN`.
*Motion:* seal fades in, title rises, subhead follows. *Source slide: 1.*

### 2. Hook / Tension  — `navy` or `parchment`
Two outcomes from one premise, side by side, big mono numbers. A short pull-quote underneath.
The contrast is the whole slide.
*Motion:* left reveals, then right, then the quote. *Source slide: 2.*

### 3. Core definition / The-only-number  — `parchment`
A single formula or concept, large, centered-left, with one supporting sentence. Set the equation in
Fraunces + mono (`ROI = extra earnings − what you spent`).
*Motion:* equation reveals term by term. *Source slide: 3.*

### 4. Enumerated breakdown  — `parchment`
A numbered set (3–6) of items with values; bar-weight or chip per item; a total callout.
*Motion:* one row per beat, total last. *Source slide: 4.*

### 5. Single-stat / Hidden-killer  — `navy` (invert for weight)
One giant mono number + a short caption + a "why it's invisible" aside. Maximum whitespace.
*Motion:* number counts up; caption follows. *Source slide: 5.*

### 6. Cliff / tiered comparison  — `parchment`
2–3 labeled tiers (`STICKER $310K` / `NEED-BLIND $0–80K` / `NEED-AWARE $120K`) with a one-line gloss
each; show it as steps, not a gradient.
*Motion:* tiers drop in top-to-bottom. *Source slide: 6.*

### 7. Figure / chart  — `navy` (chart as hero) or `parchment`
Inline SVG chart: framed baseline, end-labeled series (brand colors), gold dashed reference line,
annotated point (break-even dot + year), `FIGURE n ·` kicker, mono source line.
*Motion:* lines stroke on; reference line first; annotations last. *Source slides: 8, 11.*

### 8. Pattern bands  — `parchment`
3 horizontal bands ranked (`8–12×` / `2–3×` / `≤1×`) each with a label + gloss; weight the top band.
*Motion:* bands reveal with a slight scale. *Source slide: 9.*

### 9. Guard-rail / aside  — `parchment`
A quiet caution: a single sentence rule in Fraunces italic, hairline-boxed, lots of air. Used to slow
the viewer down between data slides.
*Motion:* simple fade. *Source slide: 10.*

### 10. Case file  — `parchment` "dossier"
Header band: `CASE FILE A` + subject line + verdict chip (`STRONG ROI` `--data-pos` / `TRADE-OFF`
`--data-gold` / `NET-NEGATIVE` `--data-neg`). Two columns: **THE MATH** (mono line items) and **VS.
THE FRIEND WHO STAYED**; a verdict sentence across the bottom.
*Motion:* header, then math column, then friend column, then verdict. *Source slides: 13–15.*

### 11. Calculator / reference  — `parchment` (sanctioned dense slide)
The one slide allowed to be dense. Numbered steps (`01`–`04`), a worked example panel, the formula,
and verdict bands (`under 8 strong` / `8–15 trade-off` / `over 15 doesn't pay back`). Tabular mono
throughout.
*Motion:* reveal step-by-step if stepping; otherwise present whole. *Source slide: 12.*

### 12. Mistakes / numbered grid  — `parchment`
A 2×3 or 3×2 grid of numbered items (`01`–`06`), each a bold label + one-line consequence. Tight but
aligned; hairline dividers.
*Motion:* stagger across the grid. *Source slide: 16.*

### 13. Bottom-line / equation  — `navy`
A balancing statement as an equation (`FINANCIAL −₮500M + NON-FINANCIAL +₮500M = even`). Big, calm.
*Motion:* terms reveal, equals last. *Source slide: 17.*

### 14. Recap  — `parchment`
2–3 numbered takeaways, each one sentence, generous spacing. No new information.
*Motion:* one per beat. *Source slide: 18.*

### 15. Close / Next  — `navy` + seal
The payoff line (`Now you can run the number`), a `NEXT — MODULE 01 · LESSON 1.1` teaser, and a mono
sources line. Seal returns to close the loop.
*Motion:* payoff rises, teaser fades, sources last. *Source slide: 19.*

---

## Choosing & sequencing

- Open on **Title**, close on **Close**; use **Section divider** (oversized Fraunces number) between
  modules within a long lesson.
- Alternate grounds: don't run three `parchment` content slides without a `navy` figure/stat for rhythm.
- Reserve **navy invert** for the moments that should land hardest (the hidden number, the key figure,
  the bottom line).
- One archetype can repeat (three case files in a row is good — the repetition *is* the structure),
  but vary the verdict chip and the data.
