# Deep Research

This is a compatibility alias for the installed `research-deep` workflow.

## Workflow

1. If a research outline already exists, use `research-deep` on that outline.
2. If no outline exists, use `research` first to create a structured outline, then use `research-deep`.
3. For academic papers or literature-gap claims, use `research-analysis` to rank evidence quality and avoid unsupported novelty claims.
4. Use `research-report` when the user needs a synthesized report from deep research results.

## Output Standard

When reporting findings, distinguish:

- confirmed evidence from papers or primary sources
- reasonable inference from the evidence
- open questions that still require deeper search

Do not treat a missing result from a quick search as proof that a literature gap exists.
