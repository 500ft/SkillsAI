# Copy checklist

For each one-liner:
- [ ] contains one number with a unit or a count
- [ ] names the method (held-out, preregistered, mesh-converged, 6 repeats...)
- [ ] no `helped / supported / worked with / assisted`
- [ ] no `honest / transparent / rigorous / without hiding`
- [ ] if pending: says what is pending and that the criterion exists

For each page:
- [ ] Problem, Constraints, Approach, Result, Next — all present
- [ ] Results block ≤ 6 items, all outcomes; specs moved to details
- [ ] Failure → Change → Result for each process step
- [ ] scope note states what is NOT claimed
- [ ] ≤ ~350 words of prose

Across surfaces:
- [ ] same project list on resume and site (top half at least)
- [ ] every quantified claim identical on both, to the digit
- [ ] `featured` means something (≤ 4)
- [ ] one voice
