# XYZ copy

Written claims about engineering work, for portfolios, resumes and project pages.

## Formats — and which one where

| surface | format | shape |
|---|---|---|
| resume bullet, headline result, project card | **XYZ** | *Accomplished **X**, as measured by **Y**, by doing **Z*** |
| case-study page | Problem → Constraints → Approach → Result → **Next** | the Result is a number; the Next names what is untested |
| process step | Failure → Change → Result | each design change is the response to a named failure |

STAR (Situation, Task, Action, Result) is an *interview answer* format. In writing it renders
Situation and Task as the same sentence twice. Do not use it for copy.

## The test for every one-liner

Can a reader who stops after this sentence repeat **one number and one method**? If not, it is
not a headline yet.

## Rules

1. Every bullet gets a number or comes off. "Prepared 32 waterjet-cut steel tabs" passes;
   "supported suspension fabrication" does not.
2. Verbs for what *you* did. Delete `helped`, `supported`, `worked with`, `assisted`.
3. **Delete every word that narrates your own honesty** — `honest`, `honestly`, `transparent`,
   `rigorous`, "without hiding". The scope note and the `Pending` marker demonstrate the
   trait; the adjective undermines it.
4. Results are outcomes. Specifications (wall thickness, screw size, dimensions) are inputs.
   Different sections.
5. Negative results are results: "the deployed threshold fires *after* the budget is violated,
   a result the paper reports rather than tunes away" is stronger than a positive claim
   because it shows the test could fail.
6. `Pending — bench torque at 7.0 V, criterion preregistered` beats bare `Pending`.
7. One voice across every surface (first or third person; pick one).
8. **Resume and portfolio must describe the same engineer.** Diff the project lists and the
   quantified bullets between them; the site said "14 tested route patterns" where the resume
   said "tested route patterns" — same claim, one surface quantified.

## When giving examples, quote the source verbatim

Do not merge two sources into one quotation. Show the current text, then the rewrite.
