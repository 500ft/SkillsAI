# Concepting Methods + Cliché→Stronger Table

Techniques to generate distinct, on-brand visual concepts for Stoic lessons, and a lookup of common
education/finance clichés with stronger Stoic alternatives.

## Divergence techniques

Apply a *different* one to each concept so the set is genuinely varied, not recolored:

- **Metaphor map** — restate the idea as a physical system (a cliff, a crossover, a tally, a scale, a
  waterline) and encode the data into that system.
- **Inversion** — show the absence/negative (what you *didn't* earn; the years you *can't* get back)
  instead of the positive.
- **Scale shift** — zoom to one telling number at full-bleed, or pull back to a 15-year arc.
- **Data-encoding swap** — same numbers, different encoding: line ↔ stacked bar ↔ slope ↔ dot plot ↔
  area. Pick the encoding that makes the *point* fastest, not the prettiest.
- **Sequence/step** — turn a static fact into a 3–4 step reveal that mirrors the narration beat.
- **Material/classical register** — express it through a Stoic motif (ledger, seal, column, engraving
  line) rendered in the design system, used once and with restraint.

## Cliché → stronger (Stoic)

| Lesson moment | Obvious (avoid) | Stronger |
|---|---|---|
| ROI / payback | piggy bank, coin stacks, $ rain | **crossover line** over a gold break-even zero |
| Hidden costs | coins, calculator emoji | **iceberg/waterline** or weighted bar with the hidden cost below the line |
| Salary comparison | bar chart in Office colors | **slope chart** home→abroad, direct-labeled, premium annotated |
| Tiers / cliff | 3 equal rounded cards | **stepped cliff** with the drop drawn, values on each step |
| Decision / choice | crossroads, two doors, signposts | **two diverging lines** from one origin point |
| Risk / lottery (H-1B) | dice, slot machine | **probability bar** (~25%/yr) with expected-attempt annotation |
| Balance / trade-off | scales of justice clip-art | **typographic equation** (`−₮500M + ₮500M = even`) |
| Growth over time | generic up-and-to-the-right | **annotated arc** with the one inflection point marked |
| "The system" / process | flowchart of boxes | **numbered editorial steps** or an Excalidraw schematic |

## Keeping it on-brand while diverging

- Every concept uses the brand palette and type — full stop. Creativity is in *composition and
  encoding*, not in new colors or fonts.
- Restraint is the brand. If a concept needs a gradient, a glow, a 3D object, or three motifs to read,
  it's the wrong concept.
- It plays under a voice: rank concepts by **clarity-per-second** first. A clever concept that takes 8
  seconds to decode loses to a plain one that lands in 2.
- Reuse the classical register sparingly — a single ledger or seal motif per section, not on every slide.

## Quick generation loop

1. State the one idea. 2. Write the cliché and discard it. 3. Spin 3–5 concepts, each via a different
technique above. 4. Cut anything off-brand or slow. 5. Recommend one; hand to design-V0.1.
