# Third-party notices

SkillsAI is a portability bundle. It does not replace or broaden the licenses of its contents.

- Existing license and notice files inside individual skill directories are preserved.
- `frontend-design/LICENSE.txt` is preserved from Anthropic's official frontend-design skill distribution.
- `hatch-pet/LICENSE.txt` and `skill-evaluator/LICENSE.txt` remain attached to those packages.
- Skills without an included license file should not be assumed to be open source merely because they appear in this repository.

The repository-level manifests, documentation, and installer scripts do not impose a blanket license on bundled skill content. Review each package and its upstream source before redistributing it separately.
